Implement `/app/solver.py`, a program that runs simulated digital PCR assays on three synthetic DNA lots and reports each lot's integrated vector copy number per cell-equivalent, with an interval, plus whether the lot supports an integration claim.

Each lot's early-passage DNA contains integrated vector copies and non-integrated vector DNA that culture dilutes. A well measures the vector target and a two-copy reference target in the same droplets, so the ratio gives vector copies per cell-equivalent for that DNA. A lot may also carry a PCR inhibitor that lowers the vector target's amplification more as the DNA input rises, while the reference target is unaffected; a spike-in control (a fixed number of synthetic template copies per well) reports the vector assay's efficiency at the input used. No-template wells show the plate background. The estimand is the integrated VCN: integrated vector copies per cell-equivalent. Culture dilutes the non-integrated DNA but does not remove all of it (`/app/SPEC.md` gives the remaining fraction), so late-passage DNA still carries some non-integrated copies.

Your program talks to the instrument over standard input and standard output with newline-delimited JSON, through `labclient.py`. You choose, per call, the lot, the passage (early, or late once `culture` has prepared it, which takes virtual days), the assay (`duplex`, `spike`, `ntc`), the DNA input from a menu and the number of wells. Each well uses one of 96 plate wells and DNA from the lot's finite stock for that passage. `status` reads the ledger and changes nothing. Results are returned only for wells you run.

Submit, for every lot, `integrated_vcn`, a 95% interval `ci` and `integration_supported` (true when the integrated VCN is at least 0.5), plus `plate.ntc_valid`, true when the plate background rate is at most 1e-4 per droplet.

A result is accepted for a case when, for every lot, the estimate and interval are finite with the lower end not above the upper end, the estimate is within 10% of the true integrated VCN (or 0.03 if larger), the interval contains the true value and is no wider than 50% of it (or 0.1 if larger), and the integration call is right, and the plate call is right. At least 6 of the 8 held-out cases must be accepted; the margin allows for the sampling variation a correct analysis still shows. Cases differ in lot composition, inhibitor strength, non-integrated carryover and plate background.

`/app/SPEC.md` has the protocol and exact model. `python3 /app/practice.py` runs your `solver.py` on a disclosed practice case whose true parameters are in `/app/practice_case.json`.
